# Earth's Network

дискорд-подобная соцсеть: серверы и каналы, личные сообщения, друзья, голосовые каналы (webrtc), файлы и картинки.
стек: cloudflare workers + d1 + durable objects (websocket) + r2, фронт на чистом html/css/js.

## деплой

```bash
npm install
npx wrangler login
npx wrangler d1 create notcord            # id вставить в wrangler.jsonc (database_id)
npx wrangler r2 bucket create notcord-files
npm run db:init:remote                    # применить schema.sql
npm run deploy
```

локально: `npm run db:init && npm run dev` → http://localhost:8787

## что есть
- регистрация/вход по нику и паролю (pbkdf2)
- серверы, приглашения по ссылке `/?join=код`, текстовые и голосовые каналы
- личные сообщения и друзья
- сообщения в реальном времени, «печатает…», удаление своих сообщений
- файлы до 25 мб (картинки и видео показываются в чате)
- голос: webrtc mesh, сигналинг через durable object

## что внутри (v2)

- **лента**: посты с фото/видео, опросы, репосты и цитаты, закреп в профиле, #теги и «в тренде», поиск (Ctrl/⌘+K), «кого читать», @упоминания, истории на 24 часа (можно только для «близких друзей»).
- **чат**: реакции, ответы, правка, закрепы, счётчики непрочитанного, онлайн-статус, «отправить пост в чат».
- **серверы**: публичные серверы с каталогом, посты от имени сервера.
- **клипы**: в голосовом канале «показать экран», любой участник жмёт «клип» — последние ~30 секунд уходят постом в раздел «клипы» (десктопные браузеры).
- **уведомления**: колокольчик, браузерные уведомления, когда вкладка в фоне.
- **модерация**: жалобы, бан только за серьёзное. админ — пользователь с id 1 или ники из переменной `ADMIN_USERS` (через запятую).
- **pwa**: можно установить на телефон/компьютер, светлая/тёмная/системная тема, горячие клавиши (`?`).

### что включается отдельно

1. **R2** (фото, аватарки, истории с медиа, клипы). после подписки на r2:
   `npx wrangler r2 bucket create notcord-files` и добавь в `wrangler.jsonc`:
   `"r2_buckets": [{ "binding": "FILES", "bucket_name": "notcord-files" }]`. пока биндинга нет, все кнопки загрузки скрыты/отключены.
2. **вход через telegram**: создай бота у @BotFather (`/setdomain` → твой домен), затем
   `npx wrangler secret put TG_BOT_TOKEN` и переменная `TG_BOT_USERNAME` (без @). пока не заданы, кнопки нет.

### обновление уже развёрнутой базы

в базе из первой версии нет новых таблиц/колонок: один раз выполни `npm run db:migrate:remote` (до деплоя новой версии).
для чистой базы достаточно `npm run db:init:remote`.
